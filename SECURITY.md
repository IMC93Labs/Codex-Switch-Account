<a id="english"></a>
## English

Codex Switch Account may interact with local Codex Desktop account/profile and session-related data. Security and privacy reports are therefore taken seriously.

### Please do not open a public Issue for

- exposure of authentication tokens, cookies, credentials or private session data;
- unintended access to another local account/profile;
- backup or restore behaviour that could expose private account data;
- paths that could overwrite or disclose unrelated private files;
- vulnerabilities that could allow unauthorized account/profile switching;
- other issues where publishing reproduction details could put users or accounts at risk.

Use GitHub's **Private vulnerability reporting** for this repository when available. If that option is not visible, do not publish sensitive reproduction details. Open only a minimal public Issue saying that you need a private security contact, without including secrets, private files, exploit details or personal data.

### Include

- affected Codex Switch Account version;
- Windows version;
- Codex Desktop version, if known;
- clear impact description;
- minimum steps needed to reproduce;
- whether the issue affects switching, launch/close handling, status refresh, backup/restore or another function;
- any relevant mitigation you identified.

Do **not** include real authentication tokens, cookies, passwords, private keys, session files, account backups or unnecessary personal information.

### Scope

Reports about Codex Switch Account's own behaviour are welcome.

Requests or reports whose purpose is to bypass OpenAI authentication, service limits, billing, access controls or account policies are outside the scope of this repository. Problems with OpenAI accounts, subscriptions, billing or service availability should be reported to official OpenAI support.

No response-time or remediation-time guarantee is provided because this is a personal hobby project maintained in free time.

## Español

Codex Switch Account puede interactuar con datos locales relacionados con cuentas/perfiles y sesiones de Codex Desktop. Por ello, los informes de seguridad y privacidad se consideran importantes.

### No abras un Issue público para

- exposición de tokens de autenticación, cookies, credenciales o datos privados de sesión;
- acceso no previsto a otra cuenta/perfil local;
- comportamientos de copia o restauración que puedan exponer datos privados de cuenta;
- rutas que puedan sobrescribir o revelar archivos privados ajenos;
- vulnerabilidades que permitan cambiar de cuenta/perfil sin autorización;
- otros problemas en los que publicar los pasos de reproducción pueda poner en riesgo a usuarios o cuentas.

Utiliza **Private vulnerability reporting** de GitHub para este repositorio cuando esté disponible. Si no aparece esa opción, no publiques detalles sensibles. Abre únicamente un Issue público mínimo indicando que necesitas un canal privado de seguridad, sin incluir secretos, archivos privados, detalles de explotación ni datos personales.

### Incluye

- versión afectada de Codex Switch Account;
- versión de Windows;
- versión de Codex Desktop, si la conoces;
- descripción clara del impacto;
- pasos mínimos para reproducirlo;
- si afecta al cambio de cuenta, cierre/apertura, actualización de estado, copia/restauración u otra función;
- cualquier mitigación relevante que hayas identificado.

No incluyas **tokens de autenticación reales, cookies, contraseñas, claves privadas, archivos de sesión, copias de cuentas ni información personal innecesaria**.

### Alcance

Se aceptan informes sobre el comportamiento propio de Codex Switch Account.

Quedan fuera del alcance las solicitudes o informes cuyo objetivo sea eludir la autenticación de OpenAI, límites del servicio, facturación, controles de acceso o políticas de cuentas. Los problemas de cuentas, suscripciones, facturación o disponibilidad del servicio de OpenAI deben dirigirse al soporte oficial de OpenAI.

No se garantiza un plazo de respuesta o corrección porque se trata de un proyecto personal mantenido como hobby en el tiempo libre.
