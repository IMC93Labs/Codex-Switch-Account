## English

Thanks for your interest in improving Codex Account Switcher.

This public repository is focused on **official releases, documentation and support**. The application source code is not published here, so contributions are mainly useful through high-quality bug reports, feature suggestions, documentation corrections and reproducible compatibility information.

### Helpful contributions

- Clear bug reports with reproducible steps.
- Compatibility reports for specific Windows or Codex Desktop versions.
- Suggestions that simplify legitimate multi-account/profile management.
- Documentation, translation or wording corrections.
- Accessibility and usability suggestions.
- Privacy or security reports following **[SECURITY.md](SECURITY.md)**.

### Before submitting

- Search existing Issues first.
- Keep one problem or request per Issue when practical.
- Explain the real use case, not only the proposed implementation.
- Remove credentials, tokens, cookies, session data, account backups and personal information from screenshots/logs.
- Do not upload private Codex conversations or account/session files.

### Out of scope

Requests intended to combine or bypass account quotas, defeat authentication, evade billing, bypass access controls, automate unauthorized account use or circumvent OpenAI policies are outside the scope of the project.

### Pull requests

Because the application source code is not published in this repository, source-code pull requests are not accepted here. Pull requests that improve public documentation may be considered when appropriate.

The maintainer may adapt, combine or decline suggestions based on project scope, safety, compatibility and available free time.

## Español

Gracias por tu interés en mejorar Codex Account Switcher.

Este repositorio público está centrado en **Releases oficiales, documentación y soporte**. El código fuente de la aplicación no se publica aquí, por lo que las aportaciones son especialmente útiles mediante informes de errores de calidad, propuestas de funciones, correcciones de documentación e información de compatibilidad reproducible.

### Aportaciones útiles

- Informes de errores claros y con pasos reproducibles.
- Informes de compatibilidad con versiones concretas de Windows o Codex Desktop.
- Sugerencias que simplifiquen la gestión legítima de varias cuentas/perfiles.
- Correcciones de documentación, traducción o redacción.
- Sugerencias de accesibilidad y usabilidad.
- Informes de privacidad o seguridad siguiendo **[SECURITY.md](SECURITY.md)**.

### Antes de enviar algo

- Busca primero entre los Issues existentes.
- Mantén un problema o propuesta por Issue siempre que sea práctico.
- Explica el caso de uso real, no solo la implementación que propones.
- Elimina credenciales, tokens, cookies, datos de sesión, copias de cuentas e información personal de capturas/registros.
- No subas conversaciones privadas de Codex ni archivos de cuenta/sesión.

### Fuera de alcance

Quedan fuera del alcance las solicitudes destinadas a combinar o eludir cuotas de cuentas, superar autenticación, evitar facturación, saltarse controles de acceso, automatizar el uso no autorizado de cuentas o eludir políticas de OpenAI.

### Pull requests

Como el código fuente de la aplicación no se publica en este repositorio, aquí no se aceptan pull requests de código fuente. Cuando corresponda, sí podrán considerarse pull requests que mejoren la documentación pública.

El mantenedor puede adaptar, combinar o rechazar propuestas según el alcance del proyecto, seguridad, compatibilidad y tiempo libre disponible.
