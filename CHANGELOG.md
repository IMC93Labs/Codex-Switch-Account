## English

### [1.7.2] - 2026-08-17

#### Fixed

- Credit balance now discards fractional credits before converting the value to euros, matching the criterion used by the Codex interface.
- New application launches activate the existing window instead of opening duplicate instances.

#### Internal

- Update manifest, SHA-256 hashes and Windows x64 artifacts are published for this version.

### [1.7.2] - 2026-08-17

#### Corregido

- Se publica el manifiesto de actualización, hashes SHA-256 y artefactos de Windows x64 para esta versión.
